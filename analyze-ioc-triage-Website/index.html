The Marshalling Yard

Quickly triages multiple IOCs (IP addresses, domains, hashes) against public threat intelligence feeds (e.g., VirusTotal, AbuseIPDB) to prioritize investigation. A marshalling yard uncouples one mixed arrival and rolls each wagon onto its own track, worst first; this tool checks each indicator and ranks what needs investigation first.

What it does

The tool takes multiple indicators of compromise and checks each one against public threat intelligence feeds, so an investigator can see which ones deserve attention first. Usage, as the README gives it: ./analyze-ioc-triage [params]. Its requirements are pandas>=2.1.0 and requests>=2.31.0.

Stated limits

At least one API key is required: a run with no key performs no lookups, writes no report, and exits 1. Each row of the report carries a Lookup Status field with a per service status of not run, failed, no data, or completed, so a blank verdict column can be told apart from a lookup that never ran or one that failed. A key given on the command line is visible in shell history and in process listings, and the tool logs a warning when one is used that way; the documented route for each key is its environment variable. No parameter in the README states how the IOCs themselves are supplied, by file, by argument, or by standard input, so how the indicators are handed to the tool is undocumented.
